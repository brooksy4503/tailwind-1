# Tailwind CSS Examples

A comprehensive demonstration application showcasing Tailwind CSS capabilities through interactive examples. This project serves as both a learning resource and a reference guide for Tailwind CSS implementation.

## Features

- 🎨 Interactive examples of Tailwind CSS features
- 🌓 Dark/Light mode with system preference detection
- 📱 Fully responsive design
- ⚡ Built with Next.js 14+ and React 18+
- 🔍 Comprehensive examples covering:
  - Layout Fundamentals (Flexbox, Grid, Spacing)
  - Visual Styling (Typography, Colors, Effects)
  - Interactive Elements (Animations, Hover States)
  - Responsive Design Patterns

## Prerequisites

Before you begin, ensure you have installed:

- [Node.js](https://nodejs.org/) (version 18.17 or higher)
- npm, yarn, or pnpm package manager

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/brooksy4503/tailwind-1.git
cd tailwind-1
```

2. Install dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```

3. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
